Política de Privacidade — OrunTV

Última atualização: 11 de setembro de 2026

2. Dados que Coletamos

2.1 Dados que Você Nos Fornece

  • Credenciais de listas M3U/Xtream: URLs, usuários e senhas que você insere para acessar suas próprias listas de canais. Estes dados ficam apenas no seu dispositivo (armazenamento local do navegador/TV) e nunca são enviados para nossos servidores.
  • Chave de API do TMDB: Se você configurar uma chave do The Movie Database para buscar pôsteres e sinopses, ela fica armazenada localmente no seu dispositivo.
  • Configurações de Cast (MQTT): Endereço do broker, usuário e senha para receber conteúdo do PC via MQTT. Armazenados localmente.
  • Credenciais Supabase (opcional): Se você fizer login para sincronizar favoritos/histórico entre dispositivos, usamos autenticação Supabase. Seu e-mail e hash de senha são gerenciados pelo Supabase (política de privacidade deles se aplica).

2.2 Dados Coletados Automaticamente

  • Dados de uso anônimos: Telemetria básica de erros e performance (ex.: falhas de reprodução, tempo de inicialização) enviada para console local — não sai do dispositivo a menos que você configure um endpoint HTTP próprio.
  • Identificador do dispositivo: Um ID aleatório gerado localmente para distinguir sua TV nas sincronizações (se habilitado).

2.3 Dados que NÃO Coletamos

  • ❌ Histórico do que você assiste
  • ❌ Listas de canais que você importa
  • ❌ Suas credenciais de IPTV
  • ❌ Localização geográfica
  • ❌ Dados de navegação fora do app

3. Como Usamos Seus Dados

  • Armazenar suas listas e credenciais localmente para que o app funcione
  • Sincronizar favoritos e progresso entre seus dispositivos apenas se você fizer login e ativar a sincronização
  • Buscar metadados (pôsteres, sinopses) do TMDB apenas se você fornecer uma chave de API
  • Exibir guias de programação (EPG) declarados nas suas listas M3U

4. Compartilhamento de Dados

Não vendemos, alugamos ou compartilhamos seus dados pessoais com terceiros.

  • O TMDB recebe apenas consultas de busca de metadados (sem identificação pessoal)
  • O Supabase recebe dados de autenticação e sincronização apenas se você optar por usar esse recurso
  • Seu broker MQTT recebe comandos de cast apenas se você configurar e ativar

5. Armazenamento e Segurança

  • Todos os dados sensíveis (senhas, tokens, chaves de API) são criptografados localmente via Web Crypto API (AES-GCM) antes de serem salvos no IndexedDB
  • As chaves de criptografia são derivadas de segredos do dispositivo e nunca saem da TV
  • Você pode apagar todos os dados a qualquer momento desinstalando o app ou usando "Sair" nas configurações

6. Seus Direitos

Você tem o direito de:

  • Acessar quais dados estão armazenados localmente (Configurações → ver fontes/canais)
  • Retificar credenciais incorretas (reimportar a lista)
  • Apagar todos os dados (desinstalar app ou "Sair" + limpar dados do navegador nas configurações da TV)
  • Portabilidade: Exportar suas listas M3U/Xtream (são seus arquivos originais)
  • Opor-se ao processamento (não usar sincronização/TMDB/MQTT)

7. Retenção

Dados locais persistem até você removê-los. Dados no Supabase (se usar sincronização) seguem a política de retenção do Supabase (padrão: 30 dias após exclusão da conta).

8. Crianças

O OrunTV não é direcionado a menores de 13 anos. Não coletamos intencionalmente dados de crianças. Se você é pai/responsável e acredita que seu filho nos forneceu dados, entre em contato para remoção.

9. Alterações nesta Política

Publicaremos alterações nesta página com data de atualização. Mudanças materiais serão notificadas no app.
