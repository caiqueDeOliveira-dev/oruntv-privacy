# OrunTV — Política de Privacidade

Página estática (um único `index.html`, sem build e sem dependências) com a
política de privacidade do app **Orun TV** para Tizen.

- Publicada via GitHub Pages: `https://caiquedeoliveira-dev.github.io/oruntv-privacy/`
- É a URL de política de privacidade usada nos portais de distribuição
  (Samsung Seller Office e TikTok Developers).

## Como editar

1. Alterar o `index.html`.
2. Commitar na `main`.
3. O GitHub Pages republica sozinho em ~1 minuto.
